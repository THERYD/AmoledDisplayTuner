# AMOLED Display Tuner

A Windows display customization tool by **RYD (Md. Tanvir Islam Riyad)**.

AMOLED Display Tuner gives your monitor a Super AMOLED-inspired appearance with deeper blacks, vibrant colours, and customizable display settings.

## Features

- 40+ built-in display filters and presets
- AMOLED-inspired visual effects
- Brightness, contrast, gamma, and colour tuning
- Custom preset creation and management
- Multi-monitor support
- Monitor brightness control through DDC/CI (supported monitors)
- Global keyboard shortcuts
- System tray and background operation
- Windows startup option
- Compare and reset display settings

## Download

1. Open the [Releases](../../releases) page.
2. Download the latest version.
3. Run the `.bat` file on Windows.

## Requirements

- Windows
- PowerShell
- A compatible display for hardware brightness control through DDC/CI

Some features depend on your monitor and system configuration.

## Important

AMOLED Display Tuner applies software-based display effects. It does not physically convert an LCD monitor into an AMOLED display.
